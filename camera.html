How to connect an OBSBOT Tail 2 with NDI
  1. Connect the camera to the venue network with an Ethernet cable. The Tail 2 is powered over the same cable from a PoE+ switch.
  2. Turn on NDI in the OBSBOT Start app (or the camera's web page) and give it a clear NDI name, e.g. MAIN FLOOR. Activate NDI there if the app asks.
  3. Add the camera here with the same name, its NDI name and its IP address (shown in the OBSBOT app).
  4. Send the video to local / assets with Stream setup on the camera card, either:
    • directly from the camera: paste the RTMP server and stream key into the camera's live-streaming (RTMP) settings, or
    • from the venue computer: in OBS with the free DistroAV plugin, add the camera's NDI source, then use the same server and key under Settings → Stream.
  5. Pan, tilt, zoom and AI tracking: use Controls on the camera card while you're on the venue network. It opens the camera's own control page.
